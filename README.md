# 🚀 Chai Code – Modern React + TypeScript + Vite Application

Welcome to **Chai Code**, a gamified and modern web application built with **React**, **TypeScript**, and **Vite**. This project showcases reusable components, beautiful animations, and a responsive UI – designed to help developers learn and build faster.

---

## ✨ Features

- ⚛️ **React + TypeScript**: Strong typing with robust component architecture.
- ⚡ **Vite**: Super-fast development and optimized production builds.
- 🧩 **Reusable Components**: Built-in components like `BentoGrid`, `HoverBorderGradient`, and more.
- 📱 **Responsive Design**: Works seamlessly across all devices.
- 🎞️ **Animations**: Powered by `framer-motion` for delightful interactions.
- ♿ **Accessibility**: ARIA support for inclusive design.
- 🎨 **Modern UI**: Styled with Tailwind CSS for clean and consistent visuals.

## 📦 Getting Started

### ✅ Prerequisites

- Node.js (v14+)
- npm or yarn

### 🚧 Installation

```bash
git clone https://github.com/your-username/chai-code.git
cd chai-code

# Install dependencies
npm install
# or
yarn install

# Start development server
npm run dev
# or
yarn dev
```

Visit: [http://localhost:5173](http://localhost:5173)

---

## 📜 Available Scripts

- `npm run dev` – Start development server
- `npm run build` – Create production build
- `npm run preview` – Preview production build
- `npm run lint` – Run ESLint checks
